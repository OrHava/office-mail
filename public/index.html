Add a mailbox

Works with Gmail, Outlook/Hotmail, Yahoo, iCloud, Walla, Zoho and any IMAP server. For Gmail, Outlook and Yahoo you must use an app password, not your normal password (see the help below). Credentials are stored only on your own server in data/accounts.json.

Advanced (non-standard providers)
How to get an app password

Gmail: turn on 2-step verification, then Google Account → Security → App passwords → create one for "Mail". Also make sure IMAP is enabled in Gmail settings.
Outlook/Hotmail: account.microsoft.com → Security → Advanced security options → App passwords.
Yahoo: Account security → Generate app password.
